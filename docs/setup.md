# Projekt einrichten

## Voraussetzungen

Für dieses Projekt benötigst du:
- Einen GitHub-Account
- Einen Internetbrowser
- Git (optional für die lokale Arbeit)

## Installation

1. Öffne das GitHub-Repository.
2. Lade das Projekt herunter oder klone es.

```bash
git clone https://github.com/Sascha2605/Projekt-Dokumentation.git
```

3. Öffne den Projektordner.

## Verwendung

Öffne die Datei index.md, um die Dokumentation zu bearbeiten.
